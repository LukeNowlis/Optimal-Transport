# Joint Transit Pattern and Headway Optimization

This project contains all my code for my optimal transport research, each code is a different model I built to better my understanding or a new model that I have created for a problem 

## Overview

The model explores how transit service can be designed to better serve passenger demand by jointly determining route patterns and service frequencies.

The project involves translating a transportation planning problem into a mathematical optimization framework and implementing the resulting model in Python.

## Methods

* Mathematical optimization
* Transit network modeling
* Route pattern optimization
* Headway optimization
* Python

## Projects 

* `Joint pattern and headway optimization.py` — Implentations of 'Joint Optimization of Pattern, Headway, and Fleet Size of Multiple Urban Transit Lines  
with Perceived Headway Consideration and Passenger Flow Allocation' with my own additions and changes 
* `kant.py` — Code for the original Kantorovich problem
